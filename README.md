# To-Do Mobile App

A simple Android To-Do mobile application developed using **Kotlin** and **Android Studio** for managing daily tasks efficiently.

## Features

* Add, edit, and delete tasks
* Set task descriptions, categories, and due dates
* Mark and manage task status
* Attach images to tasks
* Local data storage using SQLite
* Task notifications
* FAQ section

## Tech Stack

* **Language:** Kotlin
* **IDE:** Android Studio
* **Database:** SQLite
* **Platform:** Android

## Project Structure

The application includes separate components for task management, database operations, notifications, task attachments, and the user interface.

## Purpose

Developed as part of the **Mobile Application Development (MAD) Lab Exam 4** to demonstrate Android application development and local database management.
